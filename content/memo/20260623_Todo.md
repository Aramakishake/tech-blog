# 順序関係
## 音韻ゲームに関して
* 入力方式を追加したあと、対戦モードの実装が可能になる
* 紹介動画は独立しているので、まず今のバージョンの動画を作るのがいいかも

## 正規表現ゲームに関して
* まずキャラ案出しとストーリー検討が先決
  * キャラの属性
* 立ち絵はラフぐらいのものを、キャラ案とストーリー案が出たら作って良いかも
  * 精細にするのは、生成AIに投げながらできるやろという考え
* ミニゲームの部分実装はあらかたできているが、ストーリーがあらかた纏まったら着手でいいかなという感じ
* どのようなキャラにするかが決まったらワード追加のフェーズに入れそう

# 30分でできる作業群に分解

## まとめ
* このメモは、現在抱えている小さな制作タスクを一覧化して、優先順序と次の一歩を明確にするためのものです。
* 音韻ゲームと正規表現ゲームの2つのプロジェクト軸があり、前者は実装・紹介動画、後者は企画・キャラ設計・立ち絵・ワード追加が中心です。
* まずは「次に何をすべきか」を明確にし、30分で完了できる単位に分解して着手しやすくします。

## 30分でできる作業一覧
* [ ] 音韻ゲーム：現在の入力方式を整理し、追加すべき方式を3つ程度候補として書き出す。
* [ ] 音韻ゲーム：対戦モード実装のために必要な機能と画面遷移を箇条書きで設計する。
* [ ] 音韻ゲーム：今のバージョンを使った紹介動画の台本を大まかに3分割で作る。
* [ ] 正規表現ゲーム：キャラ案出しとして、属性や性格・役割を3案程度書き出す。
* [ ] 正規表現ゲーム：ストーリー検討として、起承転結の流れを簡単に構成する。
* [ ] 正規表現ゲーム：ミニゲームの現状実装で不足している要素をチェックリストにまとめる。
* [ ] 正規表現ゲーム：追加すべきワード候補を10個リストアップする。
* [ ] 正規表現ゲーム：立ち絵のラフ案を1案だけ手書き/デザインメモとしてまとめる。

## 次の進め方
1. まず「音韻ゲームの入力方式追加」と「正規表現ゲームのキャラ案出し」を各30分でやる。
2. その後、音韻ゲームは対戦モード設計、動画台本作成を順に進める。
3. 正規表現ゲームはキャラとストーリーを固めたら、ワード追加と立ち絵ラフを進める。
4. 進捗に応じて、30分タスクをさらに細かく分解して次のセッションに回す。
