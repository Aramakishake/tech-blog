- ChromeとVSCodeを同時に立ち上げていると、描画が不安定になる
  - 現象としては、画面の表示はされていないが、クリックするとYoutube一時停止できるという感じ
  - ただただ描画がされていないという話っぽい
  - ChromeやEdgeは共有のChromiumを持つ
  - VSCodeがElectronアプリであることで、Chromiumを自前で持つ(ElectronがChromiumをもう1本起動する設計になってる)
  - このChromiumの競合がGPUの管理のところで起こってしまい、描画がうまく行ってないみたい
  - また、外部ディスプレイを使用していると起こりやすいとのこと
  - 片方をGPU不使用にしてみるとうまくいくとのこと
  - →試しに、VSCode側のGPUを切ってみた
    - 切り方
      - Ctrl+Shift+P(コマンドパレット開く)→Preferences: Configure Runtime Argumentsでargv.jsonを開く
      - "disable-hardware-acceleration": true を追加し、VSCodeを再起動
      - これでGPUの加速を切る
    - 一応、VSCode使用時に影響があったら再度ONにしてChrome側のGPUを切ろうかなという感じ
