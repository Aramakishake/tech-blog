# 本題
## 前提（GitHub Pages）
まず、当ブログはGitHub Pagesという、GitHubでホームページを管理し、公開できる仕組みを用いている。

これは、
* リポジトリにホームページのhtmlやCSS, javascriptを配置しておく
* 公開元として指定したブランチ(gh-pagesなど)にpushする
* GitHub側がそのファイル群を検知して、配信開始
* https://ユーザー名.github.io/リポジトリ名/ でアクセス可能になる

という流れでホームページが公開される。

かつて利用していた
* FFFTP（FTPで送信するツール）
* お名前ドットコム（ドメインを売ってるとこ、なんか評判悪いらしいっすね）
は利用しなくてもホームページが用意できるのである！！！

## GitHub Actionsとは？
CI/CD
超ざっくりいうと、
「自動でテストしたり、自動ですぐ使えるファイル（.exeとか.htmlとか）にしてくれたら、手間が省けるね」というコンセプトのもの。

プログラマーの美徳の1つとして怠惰（手間を省くために手間をかける）を体現した仕組みだ。
