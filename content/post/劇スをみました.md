# はじめに
最近[スタァライトプロジェクト](https://revuestarlight.com/)が9周年(※)を迎えた。

(※)調べたところプロジェクト発足が2017/04/30で、舞台の初公演が2017/09頃であるとのこと。

それに際して、「劇場版 少女☆歌劇 レヴュースタァライト」のリバイバル上映をするようで、先日観た。 

まず少し映画の詳細を説明する。
当該の映画は2021/06/04公開のアニメ映画である。
2018年の夏(7-9月)アニメ「少女☆歌劇 レヴュースタァライト」の後日譚である。

単独で観ても鑑賞に耐えうるとは思うが、
少なくともアニメ1クール12話(9/30の18時までYoutubeで公開中)を観た上で臨むことを勧める。
というのも、キャラクターの背景を踏まえた上で楽しめるためである。

当該のリバイバル上映の詳細は下記の通りである。
参考：https://revuestarlight.com/news/11142/

それに絡むトピックで言うと、キネマシトラス(今季アニメだと「さよならララ」を制作)が制作しているのは注目すべき点であろう。

君もキラめきの奔流に脳を灼かれては如何だろうか。

# 現象：特典映像に関して思ったこと
日記で言えば上記で十分なんだが、
腐っても技術ブログなので、それっぽいことを絡めておきたい。

ということで、劇場版のアニメ作品の後に特典映像に切り替わったタイミングで、「ｵﾜｯ!(驚)」となった。

そうなった理由としては、特典映像がコンシューマーゲームの販促や、アニメの延長だと踏んでいたところ、声優の舞台シーンになったためである。

ただ、舞台シーンなのは数秒で納得がいった。

というのも、もともとこのコンテンツは、「舞台の出役と声優を同じくする」というところに新規性があるためである。

アニメがあまりにもウケて皆が忘れているが、起源としては舞台にあると認識している。

ただ、観ていて個人的に気になったのは以下の2点である。
- 特典映像にあまりにもシームレスに行き過ぎである点
- 聖翔以外の方は全く説明なしである点

前者は、もうちょっと映画の余韻を楽しみたかったが、そうできないため少々気になった。

後者は、舞台の方はPrimeVideoでちょろっと(#1)観たくらいの記憶で臨んでいたので、「何だっけこの服の人たち…？」となってしまった。

まぁコンテンツを履修しきってない状態で劇場に来てしまったこちらにも落ち度がある、と思いつつ、わがままハイウェイにテンションがあがりつつ、それなりに楽しんだ。

# おわりに
劇場版 少女☆歌劇レヴュースタァライトを観たという日記に絡めて驚き最小原則について紹介した。

舞台にハマるきっかけを逸し続けている私としては、下記の理由から射抜かれることはなかった。
* 声優のアイドル売りへの疑問詞
* ソシャゲに親を殺されたが如く、嫌っていたため、入口としてのスタリラに触れられなかったこと

しかし、スタァライトプロジェクトの新規性としては舞台にこそあると思うため、引き続き射抜かんとしていただきたい。

# どこかで再利用したいカスの信条
個人的な信条として、
生身の、かつ比較的美しい人間を偶像(アイドル)とするのは、(肉欲の観点で)かなり脆弱であると考えており、
土台無理だと考えているため、キャラクターと声優は切り離している立場にいる。

水は低きに流れる。それと同じく肉も快に流れる、と考えている。
