# 手順
## 1. Win+Rで`regedit` と入力しレジストリエディター起動
  - 一般にWinキー + Rを押させるタイプの指示は、危ういイメージがある。
  powershellでスクリプトをコピペさせてバックドアを仕込んだり、TeamViewerを入れさせられることで、詐欺師にPCの生殺与奪権を譲るなんてことがあるらしい。気をつけようね。
  - 正直、レジストリエディタは変なとこいじると起動しなくなるなんて話も聞くので、心配ならバックアップを取ると吉かも(補遺に記載)。

## 2. 以下のキーに移動する。

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
```

## 3. 新しいDWORD値を作成

- 右の領域で右クリック [新規] > [DWORD(32ビット)値]を選択。
- 名前を`ShowSecondsInSystemClock`に設定。

{{< img src="images/DWORD.png" alt="レジストリエディタ" caption="レジストリエディタ" >}}

## 4. 特定のDWORD値を変更

`ShowSecondsInSystemClock`のDWORD値を`1`に変更

- 値の部分をダブルクリックすることで修正可能。

{{< img src="images/DWORD2.png" alt="ShowSecondsInSystemClockの値を変更" caption="ShowSecondsInSystemClockの値を変更" >}}

やったぜ
## 5. PCを再起動する(?)

私の環境では、PCを再起動することなく、hh:mm:ssになった。

{{< img src="images/HHMMSS.png" alt="変更後の時間表示" caption="変更後の時間表示" >}}

# おわりに
今回はレジストリエディタを用いて、ツールバーの右側に表示している時刻の形式をhh:mmからhh:mm:ssに変えた。
勤務時間を1秒でも削りたい方は是非とも利用されたい。

# 補遺
## レジストリエディタのバックアップ
レジストリエディタの[ファイル]タブにある[エクスポート]で.regファイルを吐き出せる。

これを復元したいときは、.regファイルを[インポート]すれば良い。
