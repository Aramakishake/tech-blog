# 立体角の導入
まず、立体角とは、

**ある点を中心として、その点から見える空間の広がりを表す量**

である。

平面の角度\\(\theta\\)が、半径\\(r\\)の円の円周上で切り取る長さ\\(l\\)で

$$\theta=\frac{l}{r}[\textrm{rad}]=\frac{180\times l}{r\pi}[\degree]$$

と定義されるのに対し(平面角の図)、立体角\\(\Omega\\)は半径\\(r\\)の球面上で切り取る面積\\(S\\)で、

$$\Omega=\frac{S}{r^2}[\textrm{sr}]$$

と定義される(立体角の図)。

{{< img src="images/Radian2.png" alt="平面角が扇型の弧の長さで表される" caption="平面角" >}}

{{< img src="images/Steradian.png" alt="立体角が表面積で表される" caption="立体角" >}}

取りうる値は、\\([0,4\pi]\\)である。というのも、\\(S\\)(球の表面積)の最大値は\\(4\pi\\)であるためである。

極座標系の積分だと、
微小立体角は球面座標\\((\theta,\phi)\\)を用いて、

$$d\Omega=\sin\theta d\theta d\phi$$

{{< img src="images/3D_Spherical.png" alt="極座標系の例、今回の立体角は半径は登場しない" caption="極座標系" >}}

と表され、全立体角\\(4\pi\\)は

$$\int^{2\pi}_0\int^{\pi}_0\sin\theta d\theta d\phi = 4\pi$$

なお、半球の立体角は全立体角の半分なので、\\(2\pi\\)である。
# 手持ちの傘の立体角の計算
手持ちの傘について、立体角を調べた。

{{< img src="images/IMG20260826233319.jpg" alt="手持ちの折りたたみ傘の写真" caption="手持ちの傘" >}}

{{< img src="images/umbrella.png" alt="開いた傘の概形図(左)と近似した図(右)" caption="開いた傘の概形図(左)と近似して長さを測った図(右)" >}}

傘の形状は開くと上図左のような形状である。

ただ、求めようとしているのは傘の開いている立体角なので、折れ曲がっていようが直線だろうがどちらでも同じ立体角となる。

つまり、簡易的には右側のように近似できる。

また、ざっくりではあるが、それぞれの辺の長さを測ったところ、右図に記載している長さ(単位は[cm])であるとわかった。

ここから、立体角を求めよう。

まず、傘の形状を柄を軸として回転対称だと仮定して、断面を図示する。この断面において、中心軸からの開き角を\\(0<\alpha<\pi\\)とする。

{{< img src="images/approximated_umbrella_alpha.png" alt="傘の中心軸を通る面で切ったときの断面図" caption="傘の中心軸を通る面で切ったときの断面図" >}}

すると、柄の先端から見た傘の開き角は、

$$\int^{2\pi}_0\int^{\alpha}_0\sin\theta d\theta d\phi$$

また、\\(\alpha\\)は余弦定理から、以下のように求まる。

$$ 54^2 = 66^2+62^2-2\times66\times62\cos\alpha$$

$$\Rightarrow\cos\alpha=\frac{66^2+62^2-54^2}{2\times66\times62}$$

$$\Rightarrow\alpha=\cos^{-1}\left(\frac{66^2+62^2-54^2}{2\times66\times62}\right)$$

\\(\cos\alpha\\)を計算すると、

$$\cos\alpha\simeq0.646$$

である。ついでに、\\(\alpha\\)も計算すると、

$$\alpha\simeq49.79[\degree]=\frac{49.79\pi}{180}[\textrm{rad}]$$

である。

ここで、先程の立体角を求める積分を行うと、

$$\int^{2\pi}_0\int^{\alpha}_0\sin\theta d\theta d\phi$$

$$=2\pi\times
\left[-\cos\theta\right]^\alpha_0$$

$$=2\pi\times(-\cos\alpha+1)$$

$$\simeq0.708\pi[\textrm{sr}]$$

と柄の先から見たときの傘の立体角が求まった。

なお、半球の立体角は\\(2\pi[\textrm{sr}]\\)、四半球の立体角は\\(\pi[\textrm{sr}]\\)であることから、四半球よりも小さいと言えそうだ。

上記の計算では、柄の先から見込んだ傘がカバーする立体角が求まった。

ただし、実際に傘を差しているのは、頭を日差しや雨から凌ぐためのはずである。

ということで、頭の位置をざっくりと求めることにした。

個人的な検証(※)の結果、大体30[cm]程度だとわかったため、計算のしやすさのために、以下の図のように近似する(かなりガバ近似だが…)。

※傘を持つ格好をしたときの、手から鼻までの高さを計測し、30[cm]程度であることを確認した。

{{< img src="images/approximated_umbrella_beta.png" alt="傘の軸の中点に顔がある時の図" caption="傘の軸の中点に顔がある時の図" >}}

頭の中心から見た傘の開き角\\(\beta\\)は次式で表される。

$$54^2=31^2+60^2-2\times31\times60\cos\beta$$

$$\Rightarrow\cos\beta=\frac{31^2+60^2-54^2}{2\times31\times60}$$

$$\Rightarrow\beta=\cos^{-1}\left(\frac{31^2+60^2-54^2}{2\times31\times60}\right)$$

\\(\beta\\)の余弦を計算すると、

$$\cos\beta\simeq0.442$$

であった。また、ついでに\\(\beta\\)を計算すると、

$$\beta\simeq63.76[\degree]\simeq7\pi/20[\textrm{rad}]$$

であった。

これらを用いて、再度立体角を求める計算を行うと、

$$\int^{2\pi}_0\int^{\beta}_0\sin\theta d\theta d\phi$$

$$=2\pi\times\left[-\cos\theta\right]^\beta_0$$

$$=2\pi\times(-\cos\beta+1)$$

$$\simeq1.116\pi[\textrm{sr}]$$


であると求まった。
